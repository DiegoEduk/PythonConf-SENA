Ejes Académicos

Explora el universo Python

Seis líneas de inmersión técnica diseñadas tanto para aprendices en formación como para ingenieros de software senior y científicos de datos.

Track 01 terminal

Python y Desarrollo de Software

Patrones de diseño modernos, principios SOLID, Clean Code, pruebas automatizadas con PyTest, perfiles de rendimiento y tipado estricto con Mypy.

pytest clean-code typing
Track 02 psychology

Inteligencia Artificial y ML

Modelos de lenguaje extensos (LLMs), fine-tuning, agentes autónomos, redes neuronales profundas con PyTorch, Hugging Face y visión por computadora.

pytorch llms langchain
Track 03 analytics

Ciencia y Análisis de Datos

Procesamiento de datos a gran escala con Polars y Pandas, pipelines de ETL, análisis exploratorio, visualización interactiva y Business Intelligence.

polars pandas seaborn
Track 04 settings_suggest

Automatización de Procesos

RPA con herramientas abiertas, automatización de flujos de trabajo empresariales, web scraping ético, orquestación de tareas con Airflow y Celery.

airflow playwright rpa
Track 05 api

Desarrollo Web y APIs

Microservicios asíncronos ultrarrápidos con FastAPI, aplicaciones robustas con Django 5, arquitecturas basadas en eventos y GraphQL.

fastapi django asyncio
Track 06 devices

Innovación y Tecnologías Emergentes

Internet de las Cosas (IoT) con MicroPython, sensores inteligentes para agricultura de precisión en Risaralda, Cloud Native y Edge Computing.

micropython edge-ai iot
